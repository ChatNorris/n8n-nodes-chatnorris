# Changelog

## 0.1.1

- Documentation: README is now English only, as required for n8n community node verification.

## 0.1.0

Initial release.

- `ChatNorris API` credential (Bearer authentication, configurable `baseUrl`).
- `ChatNorris` node: Chatbot (Get, Get Many), Message (Send, with optional attachment), Conversation (Get, Get Many, Get Messages), Lead (Get, Get Many), Knowledge Source (Get Many, Add, Delete, Resync).
- `ChatNorris Trigger` node (polling): New Lead and New Conversation, with an optional agent filter.
